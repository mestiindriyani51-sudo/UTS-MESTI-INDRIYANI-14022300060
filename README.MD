# Aplikasi BMKG

Aplikasi BMKG adalah aplikasi yang menyediakan informasi cuaca, iklim, kualitas udara, dan gempa bumi secara cepat dan akurat. Aplikasi ini dibuat untuk membantu masyarakat memperoleh informasi terbaru mengenai kondisi cuaca dan potensi bencana alam secara real-time.

## Fitur Utama
- Prakiraan cuaca harian
- Informasi gempa bumi terbaru
- Peringatan dini cuaca ekstrem
- Informasi kualitas udara
- Notifikasi bencana alam

## Tujuan
Tujuan dari aplikasi BMKG adalah mempermudah masyarakat dalam mendapatkan informasi cuaca dan kebencanaan melalui perangkat digital sehingga dapat meningkatkan kewaspadaan dan keselamatan.

## Manfaat
- Membantu pengguna mengetahui kondisi cuaca sebelum beraktivitas
- Mengurangi risiko akibat bencana alam
- Memberikan informasi yang cepat dan terpercaya
- Membantu perencanaan perjalanan dan aktivitas sehari-hari

## Teknologi
- Android Studio
- Java / Kotlin
- API BMKG
